Here we'll be going over some common Khmer verbs that can double up as **auxiliary verbs**. An auxiliary verb is just a verb that accompanies another verb, although it can also function on its own. Lots of repetition incoming. I encourage you to read these sentences out loud, go slowly, and be mindful. Also, as a self-exercise, replace parts of each sentence to make your own sentences.

## To Want

<span class="verb">ចង់ (jawng)</span>
: to want

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ចង់</span> <span class="direct-obj">រៀនភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="verb">jawng</span> <span class="direct-obj">rien pie-saa khmer</span>
: <span class="pronoun">I</span> <span class="verb">want</span> <span class="direct-obj">to learn Khmer.</span>

<span class="pronoun">ខ្ញុំ</span><span class="verb">ចង់</span> <span class="direct-obj">និយាយភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="verb">jawng</span> <span class="direct-obj">ni-yiey pie-saa khmer</span>
: <span class="pronoun">I</span> <span class="verb">want to speak</span> <span class="direct-obj">Khmer.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ចង់បាន</span> <span class="direct-obj">លុយ</span>
: <span class="pronoun">kyom</span> <span class="verb">jawng ban</span> <span class="direct-obj">luy</span>
: <span class="pronoun">I</span> <span class="verb">want</span> <span class="direct-obj">money.</span>
: Notice that when we say "<span class="pronoun">I</span> <span class="verb">want</span> <span class="direct-obj">money.</span>", we have that word <span class="verb">បាន</span>. The word <span class="verb">បាន</span> can be thought of in this context as the verb "to get". If you want to say "<span class="pronoun">I</span> <span class="verb">want</span> <span class="direct-obj">[thing]</span>", you always use the word <span class="verb">បាន</span>, it's never just <span class="pronoun">ខ្ញុំ</span><span class="verb">ចង់</span><span class="direct-obj">លុយ.</span>

## To Need

<span class="verb">ត្រូវការ (truv kaa)</span>
: to need or require

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ត្រូវការ</span> <span class="direct-obj">រៀនភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="verb">truv-kaa</span> <span class="direct-obj">rien pie-saa khmer</span>
: <span class="pronoun">I</span> <span class="verb">need</span> <span class="direct-obj">to learn Khmer.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ត្រូវការ</span> <span class="direct-obj">និយាយភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="verb">truv-kaa</span> <span class="direct-obj">ni-yiey pie-saa khmer</span>
: <span class="pronoun">I</span> <span class="verb">need</span> <span class="direct-obj">to speak Khmer.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ត្រូវការ</span> <span class="direct-obj">បៀរ</span>
: <span class="pronoun">kyom</span> <span class="verb">truv-kaa</span> <span class="direct-obj">bier</span>
: <span class="pronoun">I</span> <span class="verb">need</span> <span class="direct-obj">beer.</span>

## To Be Able

The syntax for **to be able** is similar for the syntax used to form yes/no questions in that it involves two particles wrapping the interfix.

<span class="verb">អាច</span> <span class="direct-obj">[interfix]</span> <span class="verb">បាន</span>
: <span class="verb">aach</span> <span class="direct-obj">[interfix]</span> <span class="verb">ban</span>
: to be able

<span class="pronoun">ខ្ញុំ</span> <span class="verb">អាច</span> <span class="direct-obj">ទៅការិយាល័យៃ</span> <span class="verb">បាន</span> <span class="preposition">ថ្ងៃស្អែក</span>
: <span class="pronoun">kyom</span> <span class="verb">aach</span> <span class="direct-obj">tov ka-ri-ya-lay</span> <span class="verb">ban</span> <span class="preposition">tgnai s-aek</span>
: <span class="pronoun">I</span> <span class="verb">can</span> <span class="direct-obj">go to the office</span> <span class="preposition">tomorrow.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="direct-obj">ទៅការិយាល័យៃ</span> <span class="verb">បាន</span> <span class="preposition">ថ្ងៃស្អែក</span>
: <span class="pronoun">kyom</span> <span class="direct-obj">tov ka-ri-ya-lay</span> <span class="verb">ban</span> <span class="preposition">tgnai s-aek</span>
: <span class="pronoun">I</span> <span class="verb">can</span> <span class="direct-obj">go to the office</span> <span class="preposition">tomorrow.</span>
: Notice the <span class="verb">អាច</span> can be omitted.

## To Be Capable

<span class="verb">ចេះ (jeh)</span>
: to be capable of something
: to have the ability to do something

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ចេះ</span> <span class="direct-obj">និយាយភាសាអាល្លឺម៉ង់</span>
: <span class="pronoun">kyom</span> <span class="verb">jeh</span> <span class="direct-obj">ne-yiey pie-saa ah-luh-mong</span>
: <span class="pronoun">I</span> <span class="verb">know how</span> <span class="direct-obj">to speak German.</span>
: <span class="pronoun">I</span> <span class="verb">am capable of</span> <span class="direct-obj">speaking German.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">អត់ចេះញ៉ាំ</span> <span class="direct-obj">ភីហ្សា</span>
: <span class="pronoun">kyom</span> <span class="verb">awt jeh nyam</span> <span class="direct-obj">pi-saa</span>
: <span class="pronoun">I</span> <span class="verb">don't like</span> <span class="direct-obj">pizza.</span>
: Even though it literally means "I do not know how to eat pizza", it's semantically understood to mean that you don't like a particular food. This is colloquial and not proper.

Keep in mind that although <span class="verb">អាច</span> <span class="direct-obj">[interfix]</span> <span class="verb">បាន</span> and <span class="verb">ចេះ</span> have **some** cases where they can be substituted for the other, they still have their own use cases.

🚫 <span class="pronoun">ខ្ញុំ</span><span class="verb">ចេ</span> <span class="direct-obj">ទៅការិយាល័យៃ</span> <span class="preposition">ថ្ងៃស្អែក</span>
: <span class="pronoun">kyom</span> <span class="verb">jeh</span> <span class="direct-obj">tov ka-ri-ya-lay</span> <span class="preposition">tgnai s-aek</span>
: This is invalid and wrong, so don't do it.

✅ <span class="pronoun">ខ្ញុំ</span> <span class="direct-obj">ញ៉ាំភីហ្សា</span> <span class="verb">មិនបាន</span>
: <span class="pronoun">kyom</span> <span class="direct-obj">nyam pi-saa</span> <span class="verb">men ban</span>
: This is okay to say, but changes the semantic meaning from "I don't like pizza" to "I am unable to eat pizza". This is used more to inform of a dietary or allergy restriction, as opposed to expressing personal taste.
