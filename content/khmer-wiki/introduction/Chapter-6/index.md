In this chapter, we'll be going over some common conjunction words as well as how to compare things in Khmer.

## Conjunctions in Khmer
Knowing conjunctions also allows you to build more complex sentences. The sentence order for conjunctions is straight forward in Khmer and follows a similar pattern to English, which we'll see below.

### Because

<span class="conjunction">ពីព្រោះ (pi-pruos)</span>
: because

<span class="pronoun">ខ្ញុំ</span> <span class="verb">មិនដើរ</span> <span class="preposition">ថ្ងៃនេះ</span> <span class="conjunction">ពីព្រោះ</span> <span class="verb">ភ្លៀង</span>
: <span class="pronoun">kyom</span> <span class="verb">men daer</span> <span class="preposition">tgnai nih</span> <span class="conjunction">pi-pruos</span> <span class="verb">plieng</span>
: <span class="pronoun">I</span> <span class="verb">am not walking</span> <span class="preposition">today</span> <span class="conjunction">because</span> <span class="verb">it is raining.</span>

### But

<span class="conjunction">ប៉ុន្តែ bun-thai</span>
: but; however

<span class="preposition">ថ្ងៃនេះ</span> <span class="verb">ភ្លៀង</span> <span class="conjunction">ប៉ុន្ត</span> <span class="pronoun">ខ្ញុំ</span> <span class="verb">ចង់ដើរ</span>
: <span class="preposition">tgnai nih</span> <span class="verb">plieng</span> <span class="conjunction">bun-thai</span> <span class="pronoun">kyom</span> <span class="verb">jawng daer</span>
: <span class="preposition">Today</span> <span class="verb">it is raining</span> <span class="conjunction">but</span> <span class="pronoun">I</span> <span class="verb">want to walk.</span>

### In Order To

<span class="conjunction">ដើម្បី (daum-bei)</span>
: in order to; for

<span class="pronoun">ខ្ញុំ</span> <span class="verb">លាលែង</span> <span class="direct-obj">ការងារ</span> <span class="conjunction">ដើម្បី</span> <span class="verb">ក្លាយជា</span> <span class="direct-obj">អ្នកចម្រៀង</span>
: <span class="pronoun">kyom</span> <span class="verb">lie leng</span> <span class="direct-obj">ka-gnear</span> <span class="conjunction">dam-bei</span> <span class="verb">klaay-jie</span> <span class="direct-obj">neak jawmrieng</span>
: <span class="pronoun">I</span> <span class="verb">quit</span> <span class="direct-obj">my job</span> <span class="conjunction">in order to</span> <span class="verb">become</span> <span class="direct-obj">a singer.</span>
: <span class="pronoun">I</span> <span class="verb">quit</span> <span class="direct-obj">my job</span> <span class="conjunction">to</span> <span class="verb">become</span> <span class="direct-obj">a singer.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ហាត់ប្រាណ</span> <span class="conjunction">ដើម្បី</span> <span class="verb">ស្រក</span> <span class="direct-obj">ទម្ងន់</span>
: <span class="pronoun">kyom</span> <span class="verb">hat braan</span> <span class="conjunction">daum-bei</span> <span class="verb">sraawk</span> <span class="direct-obj">thom-gnon</span>
: <span class="pronoun">I</span> <span class="verb">exercise</span> <span class="conjunction">in order to</span> <span class="verb">lose</span> <span class="direct-obj">weight.</span>
: <span class="pronoun">I</span> <span class="verb">exercise</span> <span class="conjunction">to</span> <span class="verb">lose</span> <span class="direct-obj">weight.</span>

### Comparing

In Khmer, when comparing two things in terms of an adjective, the word jieng is used.

<span class="conjunction">ជាង (jieng)</span>
: comparative to indicate a greater degree of an adjective compared to something else

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ធំ</span> <span class="conjunction">ជាង</span> <span class="pronoun">គាត់</span>
: <span class="pronoun">kyom</span> <span class="verb">thom</span> <span class="conjunction">jieng</span> <span class="pronoun">koat</span>
: <span class="pronoun">I</span> <span class="verb">am more big than</span> <span class="pronoun">him.</span>
: <span class="pronoun">I</span> <span class="verb">am big</span><span class="conjunction">ger than</span> <span class="pronoun">him.</span>
