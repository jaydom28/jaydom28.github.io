## Yes And No

In Khmer, there are several ways to say **yes**. The word you should use depends heavily on the context and even who you're talking to.

<span class="pronoun">បាទ (baht)</span>
: If you are male, you will use this in almost every context.

<span class="pronoun">ចា (jaa)</span>
: If you are female, you will use this in almost every context.

<span class="pronoun">ករុណា (ga-ru-naa / ga-naa)</span>
: If you are speaking to a **monk**, you use this regardless of your gender. The **ga-ru-naa** is how it is spelled, but when people are speaking quickly, it often just sounds like **ga-naa**.

<span class="pronoun">ពរ (por)</span>
: If you are a monk, you use this. However if you're a monk you probably don't need this blog :wink:.

You're probably only going to use <span class="pronoun">បាទ</span> and <span class="pronoun">ចា</span>, but it is good to know these things exist. There are also various ways to say no, but they're not gender and context specific:

<span class="pronoun">ទេ (thay)</span>
: Though is usually used when writing Khmer and not when speaking, unless you're asking questions which we'll see later in this chapter.

<span class="pronoun">អត់ (awt)</span>
: This is the more common way to say no when speaking.

<span class="pronoun">អត់ទេ (awt-thay)</span>
: This is a combination of the two previous ways to say no, and it is used for emphasis. Think it it as a stronger form of **no**.

## Asking Yes/No Questions

To form a yes/no question, the following construct is used:

<span class="verb">តើ</span> <span class="pronoun">[question]</span> <span class="verb">ទេ</span>
: <span class="verb">tae</span> <span class="pronoun">[question]</span> <span class="verb">thay</span>
: <span class="verb">តើ</span> is a **particle** that precedes the question, and the <span class="verb">ទេ</span> particle marks the end of the question. Notice that the ending particle is the same as the word for **no**.

<span class="verb">តើ</span> <span class="pronoun">បងឃ្លាន</span> <span class="verb">ទេ</span>
: <span class="verb">tae</span> <span class="pronoun">bong klien</span> <span class="verb">thay</span>
: <span class="verb">Are</span> <span class="pronoun">you hungry?</span>

Although the full syntax includes the two particles that wrap around the question, the syntax is often permuted when spoken or written. The following are 4 other different ways to ask a yes/no question that all come from the previous example. These sentences all mean the same thing.

<span class="verb">តើ</span> <span class="pronoun">បងឃ្លាន</span> <span class="verb">អត់</span>
: <span class="verb">tae</span> <span class="pronoun">bong klien</span> <span class="verb">awt</span>
: Here we swap out the <span class="verb">ទេ</span> for <span class="verb">អត់</span>.

<span class="pronoun">បងឃ្លាន</span><span class="verb">ទេ</span>
: <span class="pronoun">bong klien</span> <span class="verb">thay</span>
: Here we don't even include the <span class="verb">តើ</span>.

<span class="pronoun">បងឃ្លាន</span><span class="verb">អត់</span>
: <span class="pronoun">bong klien</span> <span class="verb">awt</span>
: Same here as above, but we use <span class="verb">អត់</span>.

<span class="pronoun">បងឃ្លាន?</span>
: <span class="pronoun">bong klien</span>
: When asking a question, just saying what you want to ask in a questioning tone is often enough.

Try messing around with these different ways of asking questions using your own questions.

## Negating Verbs

Negating verbs in Khmer is as simple as sticking a <span class="indirect-obj">មិន</span> or <span class="indirect-obj">អត់</span> in front of the verb.

<span class="pronoun">ខ្ញុំ</span> <span class="verb">និយាយ</span> <span class="direct-obj">ភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="verb">ne-yiey</span> <span class="direct-obj">pie-saa-Khmer</span>.
: <span class="pronoun">I</span> <span class="verb">speak</span> <span class="direct-obj">Khmer</span>.

<span class="pronoun">ខ្ញុំ</span> <span class="indirect-obj">មិន</span> <span class="verb">និយាយ</span> <span class="direct-obj">ភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="indirect-obj">men</span> <span class="verb">ne-yiey</span> <span class="direct-obj">pie-saa-Khmer</span>.
: <span class="pronoun">I</span> <span class="indirect-obj">do not</span> <span class="verb">speak</span> <span class="direct-obj">Khmer</span>.

<span class="pronoun">ខ្ញុំ</span> <span class="indirect-obj">អត់</span> <span class="verb">និយាយ</span> <span class="direct-obj">ភាសាខ្មែរ</span>
: <span class="pronoun">kyom</span> <span class="indirect-obj">awt</span> <span class="verb">ne-yiey</span> <span class="direct-obj">pie-saa-Khmer</span>.
: <span class="pronoun">I</span> <span class="indirect-obj">do not</span> <span class="verb">speak</span> <span class="direct-obj">Khmer</span>.

One thing that you should take from this is that we cannot use <span class="indirect-obj">ទេ</span> to negate a verb.
