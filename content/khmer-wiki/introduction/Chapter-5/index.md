In this section, we'll go over the basics of how adjectives work and how to use the verb "to be".

## How Adjectives Work

In Khmer, adjectives work a bit differently than in English. For one thing, they come **after** the noun that they modify.

### Adjectives in Action

<span class="pronoun">ខ្ញុំ</span> <span class="verb">មាន</span> <span class="direct-obj">ផ្ទះ</span> <span class="adjective">ធំ</span>
: <span class="pronoun">kyom</span> <span class="verb">mien</span> <span class="direct-obj">pteah</span> <span class="adjective">thom</span>
: <span class="pronoun">I</span> <span class="verb">have</span> <span class="adjective">a big</span> <span class="direct-obj">house.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">មាន</span> <span class="direct-obj">ផ្ទះ</span> <span class="adjective">ពណ៌ខៀវ</span>
: <span class="pronoun">kyom</span> <span class="verb">mien</span> <span class="direct-obj">pteah</span> <span class="adjective">puor kiew</span>
: <span class="pronoun">I</span> <span class="verb">have</span> <span class="adjective">a blue</span> <span class="direct-obj">house.</span>

### Doubling Up As A Verb

Another thing to know about Khmer adjectives is that they can double up as a verb whose meaning is "to be [adjective]".

<span class="pronoun">ផ្ទះរបស់ខ្ញុំ</span> <span class="verb">ពណ៌ខៀវ</span>
: <span class="pronoun">pteah robaws kyom</span> <span class="verb">puor kiew</span>
: <span class="pronoun">My house</span> <span class="verb">is blue.</span>
: Here the word របស់ is introduced to represent possession. The syntax for របស់ is just "[thing] របស់ [possessor]".
: Notice how even though it literally translates to "My house blue", it is semantically understood to be "My house **is** blue".

<span class="noun">ផ្ទះ</span> <span class="pronoun">គាត់</span> <span class="verb">ធំ</span>
: <span class="noun">pteah</span> <span class="pronoun">koat</span> <span class="verb">thom</span>
: <span class="pronoun">His</span> <span class="noun">house</span> <span class="verb">is big.</span>
: Notice that the possessive can be entirely skipped.

## The Khmer Word For "To Be"

In Khmer, although adjectives are used without any "to be" verb, there exists a standalone verb that means "to be". This verb's use case is unique. It is only used to link things to identities, and **not** to describe or modify them in the same way that adjectives do.

<span class="verb">គឺជា / ជា (keu-jie / jie)</span>
: to be
: These two verbs are equivalent, but <span class="verb">គឺជា</span> is mainly used in formal written contexts. In most cases(spoken and written), <span class="verb">ជា</span> is used and we will be using that.

<span class="pronoun">គាត់</span> <span class="verb">ជា</span> <span class="direct-obj">ពួកម៉ាកខ្ញុំ</span>
: <span class="pronoun">koat</span> <span class="verb">jie</span> <span class="direct-obj">puak-mak kyom</span>
: <span class="pronoun">He</span> <span class="verb">is</span> <span class="direct-obj">my friend.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="verb">ជា</span> <span class="direct-obj">កូនសិស្ស</span>
: <span class="pronoun">kyom</span> <span class="verb">jie</span> <span class="direct-obj">goun-seh</span>
: <span class="pronoun">I</span> <span class="verb">am</span> <span class="direct-obj">a student.</span>

<span class="pronoun">ខ្ញុំ</span> <span class="direct-obj">កូនសិស្ស</span>
: <span class="pronoun">kyom</span> <span class="direct-obj">goun-seh</span>
: I am a student.
: Note that the "jie" is not necessary. This sentence and the one above mean the same thing. Often times, when using a **pronoun**, the "jie" can be left out, although it's still totally okay for it to be left in.

<span class="noun">ប្រាជ្ញា</span> <span class="verb">ជា</span> <span class="noun">អាវុធ</span>
: <span class="noun">praa-nyaa</span> <span class="verb">jie</span> <span class="noun">aavut</span>
: <span class="noun">Intelligence</span> <span class="verb">is</span> <span class="noun">a weapon.</span>
: In this case, it would sound odd to leave out the "jie".

🚫 <span class="pronoun">ខ្ញុំ</span> <span class="verb">ជា</span> <span class="adjective">ខ្ពស់</span>
: <span class="pronoun">kyom</span> <span class="verb">jie</span> <span class="adjective">kbuos</span>
: You **cannot** use the word ជា with adjectives. This is wrong and if you want to say "I am tall", you would say ខ្ញុំខ្ពស់.

✅ <span class="pronoun">ខ្ញុំ</span> <span class="verb">ជា</span> <span class="direct-obj">មនុស្សខ្ពស់</span>
: <span class="pronoun">kyom</span> <span class="verb">jie</span> <span class="direct-obj">mon-ooh kbuos</span>
: <span class="pronoun">I</span> <span class="verb">am</span> <span class="direct-obj">a tall person</span>
: This is okay to say, because rather than linking yourself to the word "tall", you are linking yourself to the **identity** of a person who is tall.
